# AI SDLC Project Scaffolder

Interactive Next.js application to configure multi-stack architectures (Microservice, Full-Stack Web, Full-Stack + Mobile, Monolith) and export ready-to-run `init-project.sh`, `feature-runner.sh`, `docker-compose.yml`, GitHub Actions `ci.yml`, and `.ai/rules/` conventions.

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

1. Push this repository to GitHub/GitLab/Bitbucket.
2. Import the repository in [Vercel](https://vercel.com/new).
3. Keep default Next.js build settings (`next build`) and click **Deploy**.
